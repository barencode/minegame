1. Различия worker() и go worker()
   -- go worker() проще говоря, вызывается фоновый процесс, закрывающийся при закрытии main;
   -- worker() стандартный вызов функции, который синхронизирован с основным ходом выполнения программы.
2. Строка "работаю" не появляется, потому что main завершился до печати в функции worker(), запущенной как горутина.
