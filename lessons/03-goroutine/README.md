1. Различия worker() и go worker()
   -- go worker() запускает отдельную горутину внутри той же программы. «Фоновый процесс» может создать неверное представление об отдельной программе.
   -- worker() выполняется в текущей горутине. После возвращения из функции выполнение продолжается со следующей строки — это мы наблюдали через Step Into и Step Out.
2. Строка "работаю" не появляется, потому что main в этом запуске завершился до печати в функции worker(), запущенной как горутина.
